# Числа питч-дека: откуда взяты

Каждое число сопровождается источником, а число без источника называется допущением.
Здесь собрано всё, что произносится со слайдов. Числа совпадают с отчётом по курсовой
работе.

| Установки с ESPHome | 156 176 | там же |
| Порог влияния CO₂ | ухудшение по шести из девяти шкал при 1 000 ppm против 600 ppm | Satish et al., 2012 |

Условия доступа к данным взяты из документации интеграций Home Assistant. Xiaomi:
связь локальная, но нужен аккаунт Xiaomi Home или вручную извлечённый токен. Tuya:
показания в штатной интеграции идут через облако. Aranet4: локально по Bluetooth, нужна
включённая функция Smart Home integration.

Аналитика Home Assistant учитывает только установки с включённой отправкой данных,
поэтому 719 800 — нижняя граница аудитории.
