# Ягель A1 — «Воздух, который видно»

## Приложение

Продуктовый лендинг настольных E-Ink часов и локального монитора воздуха. Next.js App Router, React и TypeScript в строгом режиме. Без UI-kit и внешних сервисов во время просмотра страницы.

## Деплой

Лендинг находится в деплое по ссылке `https://yagel-eight.vercel.app/`

## Запуск

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000.

## Проверка и production

```bash
npm run lint
npm run build
npm start
```

`lint` проверяет исходники приложения с нулевым допуском предупреждений. Production build также проверяет TypeScript и предварительно генерирует страницу.

## Структура

- `app/page.tsx` — композиция страницы.
- `app/_components/` — секции, навигация, часы и интерактивный пример CO₂.
- `app/globals.css` — фирменные токены, базовые стили, доступность.
- `app/landing.css` — композиция и адаптивность лендинга.
- `app/specifications.css` — инженерная основа, характеристики и открытые части продукта.
- `app/fonts/` — локальные Golos Text и IBM Plex Mono.
- `public/brand/` — исходные логотипы и пиксельный знак, сохранены без изменений.
- `public/device/` — обе исходные фотографии и векторная текстура карбонового корпуса.
- `docs/` — исходные продуктовые факты и визуальные требования.

Hero использует CSS/SVG-визуализацию корпуса по реальной фотографии. Часы обновляются по локальному времени браузера; дата также меняется автоматически. Остальные показания — явно обозначенный пример. Кнопка «Открыть окно» переключает демонстрацию высокого CO₂ и состояния после проветривания.

Реальные фотографии показаны в секциях E-Ink и сценариев использования через Next/Image. Все CTA ведут в соответствующие разделы страницы: внешние адреса покупки и исходников не предоставлены в материалах и не выдуманы.

Для клавиатуры предусмотрены заметный фокус, ссылка перехода к содержанию и закрытие мобильного меню по Escape. Плавная прокрутка и переходы отключаются при `prefers-reduced-motion`.
