# Ягель

<img src="assets/yagel-lockup.svg" alt="Логоблок «Ягель»: знак ростка и надпись ЯГЕЛЬ" height="100">

Одностраничный бренд-борд — [`brand-board.pdf`](brand-board.pdf): УТП, визуальная идея,
типографика и палитра на одном листе A4.

## Название

| | |
|---|---|
| Марка | **ЯГЕЛЬ** / **YAGEL** |
| Продукт | **Ягель A1** — настольные E-Ink часы и монитор воздуха |
| Нейминг линейки | марка + буква класса (A — воздух, S — датчик) + поколение |

Ягель — лишайник-биоиндикатор: растёт только там, где чистый воздух, и первым исчезает
при загрязнении. Где лишайник даёт признак, прибор даёт число.

## Позиционирование

| Элемент | Содержание |
|---|---|
| Конкурентные альтернативы | Aranet4, Qingping, Xiaomi, приборы на платформе Tuya; самосборка на модулях; проветривание наугад по самочувствию |
| Уникальные свойства | работает сразу после включения, без аккаунта и настройки; MQTT с автоопределением в Home Assistant; локальный HTTP/JSON API и SDK — без ключей, токенов и срока действия; открытые схема, прошивка и корпус под MIT; E-Ink без подсветки |
| Ценность | два пути к одному прибору: подключить к тому, что уже стоит, ничего не программируя, — или дорабатывать на любую глубину. Доступ к собственным данным не истекает и не отзывается; цена железа без наценки за экосистему |
| Целевой сегмент | те, кто проводит в одной закрытой комнате большую часть суток: работающие из дома, семьи с детьми, малые офисы и учебные аудитории. Внутри — и те, кому нужен готовый прибор, и те, кто хочет его дорабатывать |
| Категория рынка | бытовой монитор качества воздуха с функцией настольных часов |

Продукт закрывает оба сценария и не заставляет выбирать. Кому нужен готовый прибор —
включает и подключает к Home Assistant без единой строки кода. Кому нужно своё — получает
схему, прошивку, корпус и локальный API и дорабатывает на любую глубину. Ни один из путей
не обходной: это две равноправные двери в один продукт.

Отстройка идёт по условиям доступа к собственным данным. У части конкурентов закрыты обе
двери сразу: показания идут через сторонний сервер, API ограничен, иногда его нет вовсе или
он выдаётся по временному токену, который приходится продлевать. В итоге и тот, кому нужно
просто чтобы работало, зависит от чужого облака, и тот, кто хочет дорабатывать, упирается в
предел. Ягель отдаёт показания по своему адресу в локальной сети — без ключей, регистрации
и срока действия.

### Условия доступа к данным

| Кто | Как получают показания | Что мешает |
|---|---|---|
| **Ягель A1** | локальный HTTP/JSON, MQTT с автоопределением | ничего: без аккаунта, ключей и срока действия |
| **Приборы на платформе Tuya** | облачный API по проектному ключу | доступ к API выдаётся на пробный срок; продление запрашивается заявкой и подтверждается вручную, дальше — по платному тарифу. Интеграция пишется под инфраструктуру платформы и требует отдельного модуля. Штатного локального доступа к прибору нет |
| **Xiaomi** | облако miIO; для локального доступа нужен токен устройства | официального способа получить токен нет — его извлекают из резервных копий приложения, логов старых сборок или сторонними утилитами. Часть устройств для локального управления требует перепрошивки |
| **Qingping** | приложение и сервер производителя | штатный сценарий проходит через облако |
| **Aranet4** | локально, без облака | ограничение не в доступе, а в цене: прибор дороже в разы |

Aranet показывает, что локальный доступ сам по себе достижим — и что за него просят
соответствующую цену. Ягель занимает свободное место: условия доступа как у Aranet,
цена ближе к массовому сегменту.

Характер марки: спокойный, точный, без маркетингового шума. Тон даташита, а не рекламы —
говорим цифрами и схемами. Оценочные эпитеты и восклицательные знаки не используются.

## Слоган

**«Воздух, который видно»** — единственная формулировка, на упаковке, сайте и заставке.

Обещание не заканчивается экраном — умный дом (MQTT, Home Assistant), приложение на
телефоне с историей поверх того же локального API, несколько комнат через спутники
Ягель S1. Но экран работает и без сети: остальное — те же данные в других местах.

## УТП

> Для **тех, кто подолгу работает и спит в закрытой комнате**, мы создаём **настольные
> E-Ink часы с датчиком воздуха «Ягель A1»**, которые **одним взглядом показывают CO₂,
> температуру, влажность и давление и подсказывают, когда пора проветрить**, в отличие
> от **Xiaomi, Qingping, Aranet и приборов на платформе Tuya**, потому что **прибор
> работает полностью локально и подключается к уже имеющимся системам умного дома без
> единой строки кода, а тем, кому нужно больше, открыты схема, прошивка, корпус и
> локальный API — без ключей и сроков действия, по лицензии MIT**.

### Открытая платформа

| | |
|---|---|
| HTTP/JSON | показания по адресу прибора в локальной сети, без облака между датчиком и кодом |
| SDK | Python и C: те же вызовы, что у прошивки — датчики, свой экран, свои пороги |
| MQTT | публикация в брокер и автоопределение в Home Assistant |
| Масштаб | спутники Ягель S1 отдают данные в тот же API: от одной комнаты до этажа |

Подключение к Home Assistant не требует программирования: прибор публикует показания в MQTT
и определяется автоматически. HTTP/JSON и SDK открывают ту же телеметрию тем, кто строит
своё. Это один поток данных, доступный на двух уровнях подготовки.

Формат данных и протокол описаны в репозитории и не требуют ключей, регистрации и продления
доступа. Интеграция сохраняет работоспособность независимо от состояния серверов
производителя.

## Логотип

<img src="assets/yagel-mark-512-paper.png" alt="Знак «Ягель» на бумаге" width="128" height="128">

Знак — иконка ростка 16×16: та же графика,
что прошивка рисует на экране рядом со значением CO₂.

- один цвет: чернила `#14181A` или выворотка `#EBE9E2`, без градиентов;
- пиксели не сглаживать и не растягивать: размер кратен 16 px, интерполяция — «ближайший сосед»;
- защитное поле — не меньше 2 пикселей сетки (⅛ стороны знака);
- залитая подложка — только плашка со скруглением ⅕ стороны;
- на фото и текстуры не ставить;
- знак не перерисовывать: правка сетки расходится с прошивкой.

### Основной логоблок

<img src="assets/yagel-lockup.svg" alt="Логоблок «Ягель»: знак ростка и надпись ЯГЕЛЬ" width="151" height="64">

Бумажная подложка 151×64 со скруглением 12, поле 12 со всех сторон. Внутри — чернильная
плашка 40×40 со скруглением 8; знак 28×28 вывороткой по центру плашки, поле 6 со всех
сторон. Слово — чернила, Golos Text 800, кегль 20, трекинг `+0.14em`, зазор от плашки 10;
прописные центрируются по высоте плашки. Пропорции сохраняются при любом масштабе.

Надпись хранится кривыми, а не текстом: SVG с `<text>` зависит от наличия Golos Text
у зрителя и на сторонних площадках отрисовался бы чужим шрифтом.

| Роль | HEX | Где |

| Бумага | `#EBE9E2` | фон, подложки |
| Ягель | `#3F5F45` | акцент, ссылки |
| Тревога | `#A85F24` | только состояние CO₂ выше 1000 ppm |

## Шрифты

- **Golos Text** — заголовки и текст (гротеск с полной кириллицей);
- **IBM Plex Mono** — цифры, единицы, подписи, всё что приходит из прошивки.

Не больше двух гарнитур. Прописные подписи — трекинг `+0.16em`, цифры — tabular-nums.
